# 跨境店每周AB优化SOP（抖音+淘宝）

## 目标
- 用最小改动提升三项核心指标：点击率、咨询率、成交率。
- 每周固定做2组实验，避免同时改太多导致无法判断。

## 指标定义（统一口径）
- 点击率（CTR）= 点击量 / 曝光量
- 咨询率 = 私信咨询数 / 点击量
- 成交率 = 订单数 / 咨询数
- 升级率 = APP支持订单数 / 独立站订单数
- 有效率 = 有预算且有明确需求的咨询数 / 咨询总数

## 每周节奏（固定）

### 周一：选实验
- 从上周数据里选出最差1个环节（点击低/咨询低/成交低）
- 仅定义2个变量做AB：
  - 变量1：主图标题
  - 变量2：CTA文案 或 首屏文案

### 周二-周四：跑实验
- 每个变量只改一处，其他保持不变
- 保证样本量稳定（连续3天）
- 每日记录：曝光、点击、私信、订单

### 周五：判定结果
- 先看咨询率，再看成交率
- 若A/B差异>15%且连续2天稳定，保留优胜版
- 若咨询率上升但有效率下降>20%，判定为无效增长
- 若差异不明显，继续延长2天再判断

### 周六-周日：固化模板
- 把优胜素材加入“可复用模板库”
- 把失败素材标记原因（文案过长、利益点不清、CTA弱）

## 实验优先级（按转化漏斗）
1. 主图标题（决定点击）
2. 首屏文案（决定停留和咨询）
3. CTA句式（决定私信动作）
4. 价格呈现（决定咨询质量）
5. 免费附加支持表达（决定咨询与信任）
6. 服务边界表达（决定成交/纠纷）

## 可直接测试的AB文案

### AB-1 主图标题
- A：`跨境独立站搭建 500起`
- B：`跨境独立站搭建 500起（含免费附加支持）`

### AB-2 CTA
- A：`私信领方案`
- B：`先咨询再下单`

### AB-3 价格呈现
- A：`500起`
- B：`先诊断19.9，再按阶段推进`

### AB-4 首屏开场
- A：`你是不是不知道先做独立站还是先做APP？`
- B：`30天跨境冷启动路线图，照着做就能跑起来。`

### AB-5 附加支持文案
- A：`主服务内含FB启动建议+阶段答疑`
- B：`免费附加支持：明确频次与时效`
