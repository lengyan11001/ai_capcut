# 自建服务器独立站从零到上线步骤清单

自己买 VPS/云服务器，从零装环境、建站、上线。适合想完全掌控服务器、愿意做基础运维的卖家。成人品类需特别注意**服务商是否允许成人内容**（见下文）。

---

## 自建 vs 虚拟主机 / Shopify

| 对比项 | 自建服务器（VPS） | 虚拟主机 / Shopify |
|--------|-------------------|---------------------|
| 成本 | 月费约 30～100 元起，长期可更省 | 主机年付 500～1k，或 Shopify 月付 |
| 控制力 | 完全可控，可自装任意软件 | 受限于面板与平台规则 |
| 运维 | 需自己管安全、备份、更新 | 主机商/平台负责大部分 |
| 成人品类 | 需选**允许成人内容**的服务商 | 虚拟主机/Shopify 政策各异，需逐家确认 |

**重要**：部分云商（尤其国内）在服务条款中限制成人/敏感内容，选型时务必先看 ToS，或优先考虑对成人站相对宽松的**海外 VPS**（如 Vultr、DigitalOcean、Linode、Hetzner 等）。

---

## 阶段 0：准备

| 步骤 | 操作 | 说明 |
|------|------|------|
| 0.1 | 确定英文品牌名与域名 | 与建站方案一致，先注册 .com。 |
| 0.2 | 选择 VPS 服务商与地域 | 目标客户在欧美则选美/欧节点，延迟与合规更合适；确认服务条款允许你的业务类型。 |
| 0.3 | 选择配置 | 起步 1 核 1G～2G 内存、20～40G 硬盘即可；流量按预估访问选。 |
| 0.4 | 准备 SSH 与本地环境 | 本机能 SSH 登录服务器；可选装 SFTP 客户端（如 FileZilla）便于传文件。 |

---

## 阶段 1：购买与初始化服务器

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1.1 | 购买 VPS | 选系统：**Ubuntu 22.04 LTS** 或 **Debian 12**（便于后续装 LNMP）。 |
| 1.2 | 拿到公网 IP 与 root 密码（或密钥） | 记下 IP；若用密钥，把本机公钥加到服务器。 |
| 1.3 | 域名解析 | 在域名商处把 A 记录指到该 IP（如 `@` 和 `www`）。 |
| 1.4 | 基础安全 | 改 root 密码或禁用密码登录、只允许密钥；装 **ufw** 开 22（SSH）、80、443，`ufw enable`。 |

---

## 阶段 2：安装运行环境（LNMP 示例）

以下为常见做法，具体命令以各发行版为准。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 2.1 | 安装 Nginx | `apt install nginx`，启动并设开机自启。 |
| 2.2 | 安装 PHP 与扩展 | PHP 8.1+，扩展含 `php-fpm`、`php-mysql`、`php-curl`、`php-xml`、`php-mbstring`、`php-zip` 等（WooCommerce 需求）。 |
| 2.3 | 安装 MySQL/MariaDB | 创建数据库与专用用户，记下库名、用户名、密码。 |
| 2.4 | 配置 Nginx 站点 | 为你的域名建 server 块，root 指到后续 WordPress 目录，PHP 交给 `php-fpm` 处理。 |
| 2.5 | 配置 SSL（HTTPS） | 用 **Let's Encrypt + certbot** 免费证书，`certbot --nginx -d 你的域名`。 |

若不想手写配置，可用 **宝塔面板**（bt.cn）或 **LNMP 一键脚本** 自动装 Nginx+PHP+MySQL，再在面板里建站、绑域名、申请 SSL。

---

## 阶段 3：安装 WordPress + WooCommerce

| 步骤 | 操作 | 说明 |
|------|------|------|
| 3.1 | 下载 WordPress | 从 wordpress.org 下载最新版，解压到 Nginx 配置的网站根目录，设置目录属主为 Nginx/PHP 运行用户。 |
| 3.2 | 完成 WordPress 安装 | 浏览器访问域名，按向导填数据库名、用户、密码、表前缀；设置管理员账号与站点标题。 |
| 3.3 | 安装 WooCommerce | 后台 插件 → 安装插件 → 搜索 WooCommerce，安装并启用，按向导完成商店基础设置。 |
| 3.4 | 固定链接 | 设置 → 固定链接：选「文章名」等友好形式，利于 SEO。 |

此后产品、分类、主题、页面、菜单等与 [WooCommerce从零到上线步骤](WooCommerce从零到上线步骤.md) 中「阶段 2～4」一致，按该文档继续即可。

---

## 阶段 4：支付与合规（与其它方案一致）

| 步骤 | 操作 | 说明 |
|------|------|------|
| 4.1 | 接入支付 | 成人站需 **CCBill、Epoch、SegPay** 等成人友好网关；在 WooCommerce 中装对应插件或使用重定向到支付页。 |
| 4.2 | 隐私与政策页 | 写好 Privacy Policy、退款/退货、年龄确认（若目标国要求）。 |
| 4.3 | 包装与发货说明 | 在站点说明中性包装、隐私发货，与货代、供应商配合。 |

---

## 阶段 5：日常运维与安全

| 步骤 | 操作 | 说明 |
|------|------|------|
| 5.1 | 定期更新 | 定期 `apt update && apt upgrade`；WordPress、WooCommerce、主题、插件保持最新。 |
| 5.2 | 备份 | 数据库 + 网站目录定期备份到本机或对象存储；可配合 cron 与脚本自动化。 |
| 5.3 | 安全加固 | 限制登录尝试（如装 fail2ban）、不用默认 admin 用户名、强密码；可选 WAF 或 Cloudflare 做防护与加速。 |
| 5.4 | 监控 | 关注磁盘、内存、流量；可设简单告警（如服务商邮件/短信）。 |

---

## 预算粗估（自建方案）

| 项目 | 粗估 |
|------|------|
| 域名（年） | 约 50～100 元 |
| VPS（月/年） | 约 30～80 元/月（年付有折扣） |
| SSL | Let's Encrypt 免费 |
| 主题/插件 | 可选免费，或一次性付费 0～500 元 |
| **首年合计** | **约 500～1500 元**（视配置与是否用面板） |

---

## 可选：不用 WooCommerce 的其它自建方案

- **PrestaShop**：开源电商，多语言，安装后需自己配主题与支付插件。  
- **Magento Open Source**：功能强、资源占用与运维要求更高，适合有技术能力、规模稍大后考虑。  
- **自研前后端 + 支付 API**：开发与维护成本高，一般不推荐起步阶段使用。

起步阶段用 **VPS + WordPress + WooCommerce** 即可，流程与「虚拟主机 + WooCommerce」一致，只是服务器和环境自己管。

---

**小结**：自建服务器 = 买 VPS → 装 LNMP（或宝塔）→ 绑域名与 SSL → 装 WordPress + WooCommerce → 按 WooCommerce 文档配产品、运费、支付与合规。选服务商时务必确认允许成人品类，并做好备份与安全。
