| 文件 | 用途 |
|------|------|

## 使用顺序建议

1. **见供应商前**：完成选品调研，并打印「问供应商的问题清单」。
2. **见供应商后**：根据谈到的代发/起订/素材，选定建站方式（Shopify、WooCommerce 或自建服务器）。
3. **建站**：按对应「从零到上线」步骤清单逐项完成，同时推进货代与支付对接。

主规划中的阶段划分、预算与风险说明见根目录下的规划文档。
