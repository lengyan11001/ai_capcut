## 2) 免费附加支持规则（防扯皮版本）

- 定义：`FB指导` 与 `陪跑` 是主服务的增值支持，不单独收费、不独立上架。
- 触发条件：仅对已下单 `SKU-B` 或 `SKU-C` 用户提供。
- 频次边界：
  - 独立站500：FB建议1次 + 陪跑沟通2次
  - APP支持1000：FB建议1次 + 陪跑沟通4次
- 时效边界：
  - 独立站：交付后7天内有效
  - APP支持：交付后14天内有效
- 超范围处理：
  - 额外沟通/深度方案/新增功能，双方确认后按工作量补差。

## 5) 私信SOP（先咨询后成交）

### 首次接待（3问）
1. 你主要做哪个市场/人群？
2. 你预计投入预算范围是多少？
3. 你希望多久看到第一个可上线版本？

### 分流规则
- 预算低、方向不清：推荐 SKU-A（先诊断）
- 主要做网站上线：推荐 SKU-B（独立站500）
- 需要产品化推进：推荐 SKU-C（APP支持1000）
- 高频深度需求：在已下单基础上补差扩展

### 首聊话术模板
- `先别急下单，我先帮你判断这项目现在该先做哪一步。`
- `你发我“目标市场+预算+时间”，我给你一个可执行的阶段方案。`
- `确认方案后再开工，能明显减少返工和试错成本。`

## 6) 每周AB优化SOP（点击率/咨询率/成交率）

### 每周固定看板（周一）
- 曝光量（Impression）
- 点击率（CTR）
- 咨询率（点击到私信）
- 成交率（咨询到下单）
- 升级率（独立站到APP支持/扩展补差）

### AB测试顺序（每周最多2项）
1. 主图标题：`主服务内含附加支持` vs `跨境全流程支持`
2. 价格呈现：`500/1000明码标价` vs `先诊断19.9再匹配`
3. CTA：`私信领方案` vs `先咨询再下单`
4. 详情首屏：痛点开场 vs 结果开场

### 判定规则（防止反复改）
- 连续3天样本量足够（有稳定曝光）再判定
- 指标优先级：先看咨询率，再看成交率
- 保留前20%高转化模板，淘汰低效素材
