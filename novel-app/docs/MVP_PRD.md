# 小说 App MVP PRD（对标七猫）

## 1. 产品目标
- 在 10 周内上线移动端 MVP，验证「阅读留存 + 充值转化」。
- 提供完整闭环：登录 -> 找书 -> 加书架 -> 阅读 -> 充值 -> 持续阅读。
- 通过第三方正版内容 API 提供书籍与章节，不自建内容采编。

## 2. 用户画像
- 主用户：18-40 岁移动阅读用户，偏碎片化阅读场景。
- 核心诉求：找书快、阅读流畅、更新及时、充值便捷。

## 3. 功能边界（MVP）

### 3.1 C 端（UniApp）
- 登录：短信一键登录（MVP 可使用验证码白名单 + 测试码）。
- 书城：首页 feed、分类、榜单、推荐位。
- 搜索：搜索建议、热词、历史搜索。
- 书架：加入、移除、置顶（可选）、最近阅读排序。
- 阅读器：章节阅读、目录跳转、主题/字号/行高、自动保存进度。
- 钱包与支付：余额查询、充值下单、支付结果展示、订单列表。
- 个人中心：基本资料、阅读记录入口、订单入口。

### 3.2 管理后台（Vue3）
- 运营位：Banner、频道位、推荐位配置。
- 订单查询：按用户、状态、时间筛选。
- 用户查询：手机号/用户 ID 查询与基础信息查看。
- 内容管控：书籍屏蔽/下架（本地策略层，不改第三方源数据）。

### 3.3 后端（Spring Boot）
- 鉴权：AccessToken + RefreshToken。
- 内容代理：第三方 API 适配、失败兜底、热点缓存。
- 业务域：用户、内容、书架、阅读、钱包、支付、运营位。
- 异步任务：支付补单、章节预热、榜单刷新。
- 可观测：统一日志、健康检查、基础指标、错误告警接入点。

## 5. 核心业务流程

### 5.1 阅读闭环
1. 用户登录获取 token。
2. 首页推荐进入书籍详情。
3. 加入书架，进入阅读器。
4. 读取章节内容（优先缓存，miss 时走第三方）。
5. 阅读进度自动保存并同步。

### 5.2 支付闭环
1. 用户选择充值档位，创建订单。
2. 客户端拉起支付渠道。
3. 支付渠道回调后端验签。
4. 验签成功：更新订单状态、增加书币、写入流水。
5. 异步补单任务兜底异常订单。

## 6. 关键指标（验收口径）
- 登录成功率 >= 99.5%
- 章节打开 P95 < 800ms（缓存命中）
- 章节打开 P95 < 2000ms（缓存未命中 + 第三方 API）
- 支付订单成功率 >= 99%
- 支付回调补偿成功率 >= 99.9%
- 日志链路可追踪率 100%

## 7. 非功能约束
- 安全：支付回调验签、防重放、限流、敏感信息脱敏。
- 合规：隐私政策、用户注销入口、版权来源记录。
- 稳定性：第三方内容 API 熔断与降级策略。

## 8. 迭代里程碑
- M1（第 1-2 周）：基础工程、鉴权、首页/详情联调。
- M2（第 3-5 周）：书架 + 阅读器 + 进度同步 + 缓存。
- M3（第 6-8 周）：充值支付 + 订单 + 运营位后台。
- M4（第 9-10 周）：压测、安全加固、灰度上线。
